# Quality report

Return exactly these four sections. Do not add a rewrite.

## 1. What already fits the System Card

Name each passing check and the supporting draft text or source fact.

## 2. What breaks a stated rule

For each break, quote or precisely identify the sentence, name the Card rule,
and explain the failure.

## 3. Unsupported claims, assumptions, or missing inputs

For each item, classify it as `unsupported claim`, `assumption`, or `missing
input`. Name the fact or source that would resolve it, if known.

## 4. The one correction worth keeping

State one narrow correction in this form:

```text
When [observable situation], [specific writing behavior].
Pass test: [observable result].
Failure test: [observable result].
```

The owner decides whether the correction belongs in the System Card.
