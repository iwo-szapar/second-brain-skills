# Correction proposal

Return this before modifying a System Card:

| Field | Content |
| --- | --- |
| Affected Card field | The single field that would change. |
| Evidence | The failed sentence, quality-check observation, or owner instruction. |
| Old rule | Current approved wording. |
| Proposed new rule | Narrow replacement wording. |
| Pass test | An observable result that satisfies the new rule. |
| Failure test | An observable result that breaks the new rule. |
| Draft impact | The sentence or section likely to change after approval. |

End with: **“Approve this exact rule change?”**

No Card field or draft changes before a clear owner approval.
