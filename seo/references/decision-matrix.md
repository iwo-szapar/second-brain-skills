# SEO decision matrix

| Evidence | Default action | Guardrail |
| --- | --- | --- |
| Search-performance position 4–12 with material impressions and weak CTR | `refresh` | Fix the SERP promise and answer block before a new URL. |
| Search-performance position 11–30 with rising impressions | `expand` | Add only variants the current owner can answer without dilution. |
| Provider demand with tractable difficulty and distinct intent | `create` | Requires URL, work-item, content-plan, and canonical-owner preflight. |
| Existing first-page foothold | `defend` | Preserve distinct intent and monitor ownership or URL changes. |
| Two owned URLs answer the same job | `consolidate` | Name the owner, supporting roles, link plan, and redirect or canonical decision. |
| High volume with weak value fit or no owned proof | `ignore` | Record why it is deferred rather than inventing a content commitment. |

Use thresholds as triage aids, never as automatic publishing permission. A page
needs a specific reader job, an owned proof object, a user-value rationale, and
a safe canonical decision.
