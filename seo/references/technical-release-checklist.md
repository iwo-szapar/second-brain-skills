# Technical SEO release checklist

- Verify the rendered canonical URL, title, meta description, robots, visible page substance, and schema/content alignment.
- Verify sitemap and URL-submission state through their owning rail; an HTTP success response alone is insufficient.
- For image assets, verify `content-type: image/*`.
- Verify redirects and 404s against their intended final URL.
- Record the production check date, URL, expected marker, actual result, and any unavailable source.
- Do not submit indexing actions without the approved owner workflow, explicit approval, and provider receipt.
